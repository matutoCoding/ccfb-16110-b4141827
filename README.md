# 冷却场布置与热辐射仿真系统

TypeScript + 原生 WebGPU + IndexedDB 的风电法兰 / 齿圈 / 轴类冷却场数字孪生工作台。

## 启动

需要 Node.js 20+、pnpm 9+，以及支持 WebGPU 的 Chrome / Edge 120+（开启硬件加速）。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

物理公式独立复核（不需要浏览器和依赖安装，Node 24 可直接执行 TS 类型擦除）：

```bash
pnpm verify:physics
```

该脚本会生成内置 200 件法兰数据，用独立 RK4、`dt=2s` 参考解对比产品中的 `dt=5s` 求解器，并输出三件全曲线最大误差。当前工作区实测最大误差远低于 3%。

## 已实现页面

- **场地布局**：实测米制地坪、过道、工位、隔热屏、风机；对象可新增、表单编辑、画布拖动；隔热屏材质/高度改变后重算可见性与热通量。
- **锻件批次**：法兰、齿圈、轴类参数化截面；网格、错列、同心圆环自动排位；支持手动拖动；一键补足 300 件压测。
- **冷却推演**：表面/心部双热容节点、内部导热、辐射、对流、风机增强对流、相邻件可见性角系数；时间轴、倍速、任意件曲线、CCT 800→500℃ 冷速判定、间距和风机位置建议。
- **人员暴露**：过道/工位测点布置与拖动；辐射热通量、累计剂量、超限时长；地面热通量伪彩与 1.0 / 2.5 / 5.0 kW/m² 等值线；隔热屏移动后刷新。
- **工艺记录**：摆放快照、推演摘要、实测硬度、同钢种同截面历史批次冷速对比、JSON 导出。

## WebGPU 性能结构

300 件锻件不是每件一个光照 pass：

1. 实例化几何 Pass 输出 albedo、法线、世界坐标、材质和温度 G-Buffer。
2. CPU 按 `16 × 9 × 24` 三维簇分配锻件光源。
3. 一个全屏延迟光照 Pass 读取 G-Buffer 和当前像素所在簇的光源索引。
4. 辉光地面反射、失败描边环和人影阴影使用实例化透明 Overlay。

性能面板顶栏显示实时 FPS。点击“锻件批次 → 一键补足到 300 件压测”后验证 1080p 帧率。

- `objects`

- `batches`
- `forgings`
- `measurements`
- `records`

- 120m × 54m 冷却场；
- 200 件 Q355E 风电法兰；
- 场地隔热屏、风机、过道、工位和测点；

- 32 点硬度记录和两组历史工艺对比。

## 物理模型摘要

```text
Cs dTs/dt = K(Tc-Ts)
          - εσA Fenv (Ts⁴-Ta⁴)
          - hA(Ts-Ta)
          + Σ εiεjσ Kij Fj-vis (Tj⁴-Ts⁴)

Cc dTc/dt = -K(Tc-Ts)
```

- `Kij`：对称辐射交换面积代理，满足 `AiFij = AjFji` 的互惠结构。
- `Fj-vis`：隔热屏平面相交与高度遮挡系数。
- `h = 12 + 26 × fanFactor` W/(m²K)。
- CCT 判定使用 800→500℃ 平均冷速和钢种临界冷速。

> 说明：CCT 曲线和部分工艺阈值用于产品化演示，实际热处理工艺应以钢种正式 CCT 报告和炉批测温为准。
